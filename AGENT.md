### Conductor Integration
- **Mandate:** All feature development, bug fixes, and significant changes MUST follow the **Conductor Workflow**.
- **Source of Truth:** The `conductor/` directory contains the project's product definition, tech stack, and active tracks.
- **Workflow Guide:** Refer to `conductor/workflow.md` for the specific lifecycle (TDD, branch naming, plan updates, git notes, and checkpoints) required for all tasks.
- **Active Track:** At the beginning of every session involving development, you MUST verify the current branch and consult `conductor/tracks.md` and the relevant `plan.md` to ensure continuity.
